# 1024职场说话 · AI 职场表达陪练

> 1024 造物挑战参赛作品 ｜ 单文件网页应用 ｜ 面试问答 · 即兴表达 · 工作汇报三大高频场景

面向职场人的 AI 口语表达陪练网页应用：面试前刷高频真题、会议被点名发言前练即兴、周报/立项/述职汇报前做开口彩排——录音作答，六维评分加五档评级，练完即有示范参照。

## 功能特性

- **三大核心场景**：
  - 面试问答：高频真题题库，支持「快速 10 题 / 完整 20 题」两档
  - 即兴表达：32 张即兴话题卡，随机抽题开口练
  - 工作汇报：12 套汇报模板（含「结论先行 / 数据支撑 / 下一步明确」要点卡）
- **每日个性化题库**：一键生成当日练习计划
- **六维评分 + 五档评级**：感染力、流畅度、结构、内容等维度量化反馈
- **示范话术**：内置 20 道面试示范话术，练完即有参照
- **逐字比对 + AI 深度点评**：配置大模型后解锁

## 快速开始

```bash
# 方式一：直接双击 index.html 用浏览器打开
# 方式二：本地起服务（推荐）
python3 -m http.server 8080
# 访问 http://localhost:8080
```

手机或电脑浏览器均可，免安装免注册。

## 配置 AI 能力（可选）

在设置面板填入任意 OpenAI 兼容接口的 `Base URL + API Key + 模型名`，即可解锁 AI 出题与 AI 深度点评；不配置也可使用内置离线评分引擎完成全部练习。

## 技术架构

- 单 HTML 文件（约 308 KB），零构建、零依赖、零后端
- Web Audio API 实时声学采集与分析
- Web Speech API + 讯飞实时语音转写双转写通道，自动降级
- OpenAI 兼容接口调用大模型，结构化 JSON 提示词 + 容错解析
- localStorage 本地持久化

## 与「开口练」的关系

本项目与姊妹项目 [kaikoulian-ai-coach](https://github.com/evcgs/kaikoulian-ai-coach) 共享同一套「录音 → 转写 → 六维评分」技术底座，差异在于内容与侧重：

| | 开口练 | 1024职场说话 |
|---|---|---|
| 场景 | 日常/演讲/朗诵/美文 | 面试/即兴/汇报 |
| 侧重 | 普通话开口与发音 | 结构化职场表达 |
| 特色 | 提词器跟声高亮、逐字比对 | 话题卡、汇报模板、示范话术 |

## 隐私说明

录音不上传，数据仅存本机浏览器 localStorage；你配置的 API Key 仅存本机。
