② 进入控制台 → 创建应用 → 开通「实时语音转写」服务（新用户有免费试用包）
③ 在「实时语音转写」服务的 WebSocket 接口认证信息中复制 APPID 与 SecretKey，填到上面并保存
用量与授权：讯飞控制台 → 实时语音转写 → 实时用量（剩余时长 / 路数）。报「授权/额度不足」时，先确认试用包已领取且未过期。
「测试连接」会发送 0.1 秒静音音频验证鉴权与网络，不消耗转写时长。失败时按提示处理：密钥错 → 核对 AppID / SecretKey；授权不足 → 控制台领试用包；超时 → 检查网络或防火墙对 rtasr.xfyun.cn 的 WebSocket 限制。
关闭后回到浏览器自带语音识别；在不支持语音识别的浏览器（华为 / 微信内置等）上会退回「按声音与时长」的基础评分。

配置任意 OpenAI 兼容接口（火山方舟 / DeepSeek / OpenAI…）即可 AI 出题；不配置也能完整练习，内置离线出题自动兜底。在华为 / 微信内置等缺少语音识别的浏览器上，可开启「语音增强」获得完整评分。
